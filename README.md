## Start here: Social Content Reader

A local Python + Codex workflow for inspecting a social post before relying on its explanation. It preserves source evidence, labels partial results, and separates evidence preparation from understanding.

**[Open the walkthrough →](https://cesard0.github.io/social-content-reader/)**

- [Product decisions and tradeoffs](https://github.com/Cesard0/social-content-reader/blob/main/docs/case-study.md#decisions-that-matter): preserve useful media after subtitle errors without calling the result complete.
- [Complete public example](https://github.com/Cesard0/social-content-reader/blob/main/docs/public-example.md): source videos, prepared evidence, actual illustrative answers, and a short event the sampled frames miss.
- [Code and verification](https://github.com/Cesard0/social-content-reader): cache integrity, failure handling, and an evaluation workflow with explicit evidence boundaries.

Personal project, developed with Codex assistance in implementation and documentation. Public examples show specific behavior and limitations; they do not establish customer adoption, production reliability, or measured user benefit.
